# Каталог MCP-серверов: что поставить себе

Справочник к занятию 3. Пригодится для домашки «по желанию»: выбрать и поставить один сервер
под свою задачу.

> Ссылки и названия пакетов проверены 15 октября 2026. Экосистема MCP меняется быстро: если
> что-то не открывается или пакет переименовали, ищи актуальный адрес в
> [реестре серверов](https://registry.modelcontextprotocol.io) и не мучайся.

---

## Сначала про количество

В каталогах сейчас больше десяти тысяч MCP-серверов. Большинство написаны на выходных и
ломаются при первой же попытке, так что гнаться за количеством не нужно.

Два правила:

**Ставь только то, чем реально пользуешься.** MCP убирает трение в работе, которая у тебя
уже есть. Новых привычек он не создаёт: если ты не ведёшь задачи в Notion, MCP к Notion не
заставит тебя их вести.

**Три-пять серверов: оптимум.** Каждый подключённый сервер занимает место в контекстном окне
ещё до того, как ты что-то спросил. Помнишь контекстное окно с занятия 2? Вот это ровно оно.
Двадцать серверов не сделают агента умнее, а памяти ему оставят меньше.

## Как поставить

Проще всего не запоминать ничего: скажи агенту своими словами, какой сервер хочешь, и дай
ссылку из таблицы. Он сам разберётся со способом. Именно так мы ставили Playwright.

Если интересно, что он делает под капотом, большинство серверов ставится одной командой:

```bash
# поставить сервер для всех проектов сразу, так и ставим по умолчанию
claude mcp add --scope user <имя> -- npx -y <пакет>

# если нужен ключ доступа
claude mcp add --scope user <имя> -e API_KEY=твой-ключ -- npx -y <пакет>

# что уже стоит
claude mcp list

# в какой области стоит конкретный сервер
claude mcp get <имя>

# удалить
claude mcp remove <имя>
```

⚠️ **`--scope user` не забывай.** Без него сервер встанет только в ту папку, откуда ты его
поставил: в другом проекте его уже не будет. Самая частая причина «вчера работало, сегодня
нет».

⚠️ **Руками в файлы конфига MCP-серверы не прописываются.** Ни в `settings.json`, ни в
`.mcp.json`: Claude Code читает их из своего реестра, который правится командой
`claude mcp add`. Написанное в файл вручную выглядит правильно, но не подключается.

**После установки перезапусти Claude Code:** новые инструменты подхватываются при старте
сессии. Проверить, что всё подключилось: команда `/mcp` прямо в диалоге.

**Поставил, запиши.** Допиши сервер в таблицу «MCP-серверы» в своём глобальном `CLAUDE.md`
(её завёл промпт Playwright). По ней всё восстанавливается на новом компьютере.

⚠️ **Так ставятся не все.** Часть сервисов держит сервер у себя в облаке (подключаешься по
адресу, ничего не скачивая), другие идут Python-пакетом или плагином Docker. В таблицах такие
помечены отдельно, смотри колонку «Установка».

## Запасной браузер: agent-browser

Бывает, что Playwright тупит: виснет на скриншотах, браузер перестаёт откликаться. Тогда есть
[**agent-browser**](https://github.com/vercel-labs/agent-browser) от Vercel. Это не MCP-сервер,
а отдельная программа для управления браузером: агент вызывает её командами, как git.
Плюс в том, что она тратит заметно меньше контекста на чтение страницы.

Как поставить: попроси агента.

```text
Поставь agent-browser (https://github.com/vercel-labs/agent-browser) по инструкции
из его README, скачай для него браузер и проверь: открой https://www.ycombinator.com/rfs
и расскажи, что там. Дальше, когда я прошу поработать с сайтом, используй его.
```

Он ставится через npm, а на macOS ещё и через Homebrew. Нужен тот же Node.js, что и для
Playwright.

## Безопасность: четыре правила

1. **Давай минимально необходимый доступ.** Серверу хватит одной папки: не давай весь диск.
   Сервис умеет выдавать токен с ограниченными правами: бери такой.
2. **Проверяй, что агент собирается сделать.** Двадцать ошибочно созданных страниц в
   заметках поправимы. Удалённые данные из боевой базы, может быть, уже нет.
3. **Формулируй точно.** «Обнови таблицу» плохо. «Добавь строку с сегодняшней датой и
   значениями X, Y, Z» хорошо. С внешними сервисами цена расплывчатой формулировки выше:
   действие уходит наружу.
4. **Не вставляй ключи доступа в промпты.** Ключ указывается один раз при установке сервера
   и хранится в конфигурации.

И про сам выбор: ставь то, у чего понятный автор, сам сервис или крупный проект с живым
репозиторием. Сервер получает доступ к твоим данным, «нашёл на просторах» тут плохой
критерий. Подробно о безопасности проекта поговорим на занятии 7.

## А если нужного сервера нет?

Его можно написать самому: MCP открытый протокол. Пошаговый факультатив, где агент
пишет сервер к твоему Telegram: [github.com/ahtlv/diy-mcp](https://github.com/ahtlv/diy-mcp).

Если захочется копнуть:
- [Официальная документация MCP](https://modelcontextprotocol.io)

одному инструменту.
